# ADR-0003: идемпотентные команды и доставка outbox

- Статус: принято для R0
- Дата: 2026-08-17

## Idempotency-Key

`POST /api/v1/tasks/:taskId/complete` требует ключ длиной 8–200 символов. Ключ ограничен актором и конкретной операцией `task.complete:<taskId>`. После доменной нормализации команды API вычисляет SHA-256 payload.

IdempotencyRecord резервируется в той же транзакции, что Task, Interaction, Opportunity, AuditLog и OutboxEvent. Успешный результат записывается до commit:

- тот же ключ и hash возвращают сохранённый результат без повторных изменений;
- тот же ключ и другой hash возвращают HTTP 409;
- rollback команды удаляет и незавершённую резервацию;
- конкурентная вставка использует `INSERT ... ON CONFLICT DO NOTHING`, поэтому второй запрос ждёт исходную транзакцию и видит только её целиком завершённый результат.

`expires_at` задаётся через 24 часа. Физическая очистка просроченных записей будет отдельной регламентной задачей и не влияет на корректность команды.

## Outbox relay

Relay арендует готовые события атомарным CTE с `FOR UPDATE SKIP LOCKED`. Claim увеличивает `attempts` и записывает `locked_at/locked_by`. Публикация выполняется вне транзакции:

- успешная публикация подтверждается только текущим владельцем аренды;
- ошибка публикации освобождает событие и назначает экспоненциальный retry до пяти минут;
- ошибка acknowledge после успешной публикации не маскируется как ошибка транспорта;
- после падения worker просроченная аренда становится доступна другому экземпляру.

Гарантия доставки — at-least-once. Потребители обязаны дедуплицировать сообщения по стабильному `OutboxEvent.id`. Транспорт задаётся через `OutboxPublisher`; RabbitMQ-адаптер подключается отдельно после фиксации exchange, routing key, TLS и credential policy.

## Ограничения проверки

Логика replay, конфликтов, rollback, backoff и acknowledge проверяется детерминированными тестами. Реальные конкурентные PostgreSQL-тесты `SKIP LOCKED` остаются обязательными перед pilot gate, поскольку локальный Docker Engine недоступен.
