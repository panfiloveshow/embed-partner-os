# Embed Partner OS — система развития эмбедной видеосети

**Готовое рабочее место команды, которая масштабирует партнёрскую сеть
видеохостинга:** от поиска площадок и первого касания до размещения плеера,
SLA-контроля и недельного отчёта руководителя.

---

## Какую боль закрывает

Развитие эмбедной сети обычно живёт в Excel и мессенджерах: база партнёров
ни у кого «не в одном месте», менеджер забывает следующий шаг, зависшие сделки
всплывают постфактум, руководитель собирает отчёт вручную по понедельникам,
а после ухода сотрудника его контакты и договорённости теряются.

Embed Partner OS заменяет этот «зоопарк» одним процессом с прозрачными
правилами и полной историей.

## Что внутри (12 контуров)

- **Сегодня** — приоритетная очередь задач с объяснимым Priority Score;
  завершение задачи только вместе с результатом и следующим шагом.
- **Воронка S0–S10** — канбан+таблица на одном API-ответе, переходы с валидацией
  обязательных данных, история стадий.
- **Реестры** — организации (группы брендов/юрлица/домены) и контакты M:N,
  дедупликация, безопасное слияние дублей, мягкий архив.
- **Импорт CSV/XLSX** — предпросмотр, разрешение конфликтов, атомарный коммит,
  построчный протокол.
- **Радар** — потенциальные партнёры с сайта или списка: безопасное
  исследование страницы (HTML/sitemap/RSS), контакты и ЛПР, детекция
  видеостраниц (L1 headless-браузером), оценка трафика Similarweb*,
  объяснимый Partner Score, готовый черновик первого письма.
- **Placement + L0-монитор** — реестр размещений, автоматическая проверка
  доступности iframe, алерты и технические задачи после двух ошибок подряд.
- **SLA и эскалации** — версионные пороги, инциденты, однократная эскалация
  руководителю.
- **Отчёты** — неизменяемый недельный снимок (понедельник–воскресенье, MSK),
  автозапуск по понедельникам, доставка дайджеста (Telegram/webhook).
- **Доступы** — 7 ролей, точечные разрешения, аудит каждого действия,
  защита от self-lockout; вход через корпоративный SSO **или** встроенный
  логин/пароль.

\* точная панельная статистика требует ключа Similarweb; без него доступен
бесплатный режим Tranco (`RADAR_TRANKO_ENABLED=1`, оценка по глобальному
рангу) либо система честно показывает «нет данных» — остальные признаки
(ЛПР, регион, контакты, видео) работают всегда.

## Почему это выгодно покупать

- **ЛПР находится автоматически**: менеджер получает ФИО и должность
  руководителя юрлица прямо из выписки ФНС — минус часы поиска «кто
  принимает решения», плюс поддержка ИП.
- **Факторы Partner Score заполняются сами**: география из адреса ФНС,
  объём видео из карты сайта — меньше ручного труда на каждого кандидата.

## Почему это безопасно покупать

- **Аудит каждого действия** — append-only журнал, который нельзя подделать
  даже администратору БД (триггеры на уровне PostgreSQL).
- **Идемпотентные операции** — повтор запроса не создаёт дублей; конфликты
  ключей детектируются.
- **SSRF-safe** исследование внешних сайтов, подписанные вебхуки (HMAC).
- Чек-лист для службы безопасности: `docs/security-checklist.md`.

## Внедрение за один вечер

```bash
cp .env.example .env && docker compose -f compose.prod.yaml up -d --build
```

PostgreSQL, миграции, API, веб-интерфейс, все фоновые процессы — 12 сервисов
одной командой. Health-check для мониторинга: `/api/v1/health`.
Резервное копирование: `scripts/backup.sh` (cron-ready).

## Состав поставки

- Исходный код монорепозитория (NestJS + React + TypeScript + Prisma)
- Docker-образы и compose для продакшена
- Документация: 12 runbooks, ADR-архив, чек-лист безопасности
- Тестовый контур: **335+ автотестов** (unit + компонентные + интеграционные),
  CI-пайплайн GitHub Actions

## Формат лицензии

неограниченные пользователи внутри компании, исходный код передаётся в
депозит либо открытый — по договорённости. Поддержка и обновления —
