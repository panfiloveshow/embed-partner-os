# Демо-сценарий Embed Partner OS (15 минут)

Подготовка: стек запущен (`compose.prod.yaml`), выполнен seed с демо-данными
(`--profile seed run --rm seed`). Откройте `http://<хост>:8080`.

Совет: держите второй монитор/окно с реальным сайтом-кандидатом (любой
медиа/блог), чтобы показать живую проверку.

## 1. Вход и «Сегодня» (3 мин)

- Экран входа → учётная запись менеджера (seed).
- Обратите внимание на приоритетные группы **Критично / Сегодня / Можно позже /
  Ожидание** и объяснимый Priority Score (раскрыть факторы у задачи).
- Завершите одну задачу: показать, что система требует **результат + следующий
  шаг** — именно это не даёт сделкам «зависать».

## 2. Воронка (2 мин)

- Переключите представление канбан ↔ таблица: данные идентичны, т.к. один
  ответ API.
- Попробуйте перевод сделки без обязательных данных стадии — система покажет
  точный список недостающего. Заполните → переход; в истории появится запись.

## 3. Радар — главная фишка (4 мин)

- Добавьте URL реального сайта → проверка запускается автоматически.
- Через ~15 секунд раскройте карточку: язык, частота публикаций, найденные
  контакты/ЛПР, признаки видеостраниц, объяснимый Partner Score по факторам.
- **Покажите ЛПР**: ФИО и должность руководителя со ссылкой на выписку ФНС
  («Официальные открытые данные ЕГРЮЛ») — менеджеру не нужно искать «кто
  решает». Для ИП ФИО берётся из названия записи.
- Покажите **регион** в факторах («г. Москва, Россия», 8/8) и Telegram-канал
  с пометкой «канал площадки»/«канал автора».
- Покажите **готовый черновик первого письма** и следующий шаг.
- Проговорите честность: без ключа Similarweb трафик оценивается бесплатно
  через Tranco или фактор = 0 с баннером.

## 4. Организации и контакты (2 мин)

- Карточка организации 360°: связанные контакты, возможности, размещения,
  аудит.
- Поиск дубля → безопасное слияние: история и взаимодействия переходят к
  целевой записи, исходная помечается `merged_into`.

## 5. Импорт (1 мин)

- Загрузите подготовленный CSV/XLSX из 10–20 строк: предпросмотр, конфликты,
  атомарный коммит, построчный протокол.

## 6. Отчёты руководителя (2 мин)

- Экран «Отчёты»: результат недели, воронка, исполнение, решения, реестр
  исключений.
- Упомяните: снимок неизменяемый, публикуется автоматически в понедельник
  10:00 MSK, дайджест летит в Telegram или корпоративный webhook.

## 7. Доступы и безопасность (1 мин)

- Настройки → Роли и доступ: 7 ролей, точечные разрешения, деактивация.
- Слова для службы безопасности: append-only аудит, идемпотентность,
  SSRF-guard, чек-лист `docs/security-checklist.md`, 335+ автотестов в CI.

## Вопросы-ответы на демо

- **«А если наш процесс стадий другой?»** — машина стадий и пороги SLA
  версионно настраиваются, переходы с валидацией данных.
- **«Где хостится?»** — ваш контур/Docker; TLS на границе; секреты в вашем
  secret-manager.
- **«Что если упадёт воркер?»** — lease/retry/dead-letter, события не теряются
  (transactional outbox), автоперезапуск compose.
